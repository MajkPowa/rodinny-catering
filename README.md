# Rodinný catering — náhled webu

Veřejný návrh redesignu stránky Rodinný catering. Statické HTML, CSS a JavaScript; vlastní fotografie a lokálně hostované fonty.

GitHub Pages publikuje obsah větve `main` z kořene repozitáře. Soubor `.nojekyll` zachovává hotové HTML bez Jekyll buildu.

Poptávkový průvodce připraví e-mailový koncept, soubor `.eml` nebo text ke kopírování. Návštěvník dokončí odeslání ve své poštovní aplikaci.

Tento repozitář obsahuje pouze zveřejňované soubory náhledu. Fontové licence jsou v `assets/fonts/`.

Plynulé nástupy obsahu, odezva ovládacích prvků a přechody dialogů respektují nastavení omezeného pohybu. Obsah zůstává čitelný i bez animací.
